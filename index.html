Infraestrutura própria, do zero

Não é só código de sistema: eu construí a infraestrutura inteira que mantém os produtos rodando e se atualizando sozinhos em dezenas de clientes.

Versionamento e distribuição

Git + GitHub Releases + FTP

Todos os apps e módulos são versionados em Git com releases publicados no GitHub. Os agentes instalados nos clientes se auto-atualizam baixando a release mais recente — e se o GitHub falhar, existe fallback automático via FTP próprio.

Git / GitHub ReleasesFallback FTPAuto-updateRepos por módulo
🔐

VPN própria

Rede privada WireGuard

Rede VPN própria com WireGuard conectando o servidor central aos clientes — acesso remoto seguro aos bancos e serviços de cada unidade sem expor nada na internet aberta, integrado ao servidor de sincronização.

WireGuardRede privadaAcesso remoto seguro

Servidor central de monitoramento

API pública + helpdesk

Servidor central que recebe status, ocorrências e telemetria de todos os clientes: API REST documentada (Swagger/OpenAPI), consumo atômico de flags de execução, abertura automática de chamados, agenda integrada e métricas de operação.

FastAPISwagger/OpenAPIMétricasChamados automáticos
